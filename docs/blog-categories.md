# 블로그 카테고리

글의 frontmatter에 `Category`를 추가한다. 대문자 C를 사용하며, 한 글에는 카테고리 하나를 지정한다.

```yaml
---
title: "알고(Algo) 풀자: 시간복잡도"
summary: "알고리즘 : 시간복잡도"
date: "Aug 27 2025"
draft: false
Category: "개발"
tags:
  - Algorithm
---
```

- 생략한 글은 `미분류`로 표시한다. 빈 문자열은 허용하지 않으며 앞뒤 공백은 제거한다.
- 카테고리 이름은 같은 표기를 사용한다. 예를 들어 `개발`과 `게임 개발`은 서로 다른 카테고리다.
- 공개 글에 사용된 카테고리만 블로그 목록에 나타나며, 선택하면 해당 카테고리의 공개 글을 최신순으로 표시한다.
- 카테고리 페이지는 `/blog/category/개발` 형식이며 한글·공백 등은 링크에서 URL 인코딩한다. 빌드 시 생성되므로 새 카테고리를 배포하려면 다시 빌드한다.
- 글 상세 상단의 카테고리도 같은 목록으로 연결된다. 목록의 검색·정렬·페이지 이동은 선택한 카테고리 안에서 작동한다.
- `tags`는 유지되며 글 카드와 검색에 계속 사용된다. 프로젝트 목록의 태그 필터도 유지된다.
- 카테고리는 초안의 공개 정책을 변경하지 않는다. 기존 상세 경로와 RSS에는 별도의 초안 제외 정책이 적용되지 않는다.
