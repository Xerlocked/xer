# 들어가며

2026년 지금의 IT업계는 AI가 지배하고 있습니다. 2020년 GPT-3 Shock 이후로, 빠르게 발전하고 모든 산업에서 AI 도입을 검토하고 적용하는 단계에 진입하고 있습니다. 이에 따라 저는 AI가 어떻게 발전해왔고 현재는 어떤 상태인지 알아보기 위해 글을 작성하고 있습니다. 물론 전 AI 개발자, ML/DL 전공을 하지 않았습니다. 그래서 글에 빈틈이 있을 수도 있습니다. 언제든지 피드백을 주십시오. 환영합니다.

# 기계학습

맨 처음 Machine Learning(이하 ML)이란 말이 등장한 건, 1959년에 등장했습니다. IBM 직원이자 인공지능 분야의 선구자인 Arthur Samuel은 체스에서 각 진영의 승률을 계산하는 컴퓨터 프로그램을 발명하면서 소개되었습니다.

![samuel](./000_samuel.avif)
_Arthur Samuel_

ML 개념은 단순합니다. 데이터가 있으면 컴퓨터 스스로 학습하는 알고리즘입니다. 즉, 데이터만 주어지고 **알아서** 공부하라는거죠. 그러면 데이터는 뭐를 줘야할까요? 1960년대라고 생각해보면 그렇게 다양한 데이터는 없을 것 같습니다. 아마 데이터는 숫자, 이미지, 텍스트정도가 있을 겁니다.
